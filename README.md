## Objetivo

O GestãoHair é um sistema desktop para auxiliar o gerenciamento de um salão de beleza, organizando clientes, produtos e agendamentos.

## Funcionalidades

- Login de acesso.
- Cadastro e consulta de clientes.
- Cadastro e consulta de produtos.
- Cadastro e consulta de agendamentos.
- Integração com banco de dados MySQL.
- Resumo quantitativo dos registros cadastrados.

## Banco de dados

O sistema utiliza MySQL para armazenar clientes, produtos e agendamentos.
